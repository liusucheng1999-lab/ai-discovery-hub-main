## 🎯 核心脚本功能说明

### 1. 📊 数据获取脚本

#### `scripts/fetch-ai-tools.js`
**功能**: 从外部API获取AI工具数据并存储到数据库
**用途**: 
- 定期更新AI工具数据库
- 从ProductHunt等平台获取新工具
- 自动化数据收集流程

**使用方法**:
```bash
node scripts/fetch-ai-tools.js
```

### 2. 🗑️ 重复工具清理脚本

#### `complete-duplicate-cleanup.js` ⭐
**功能**: 完整的重复工具清理流程（AI分析 + 删除计划 + 自动执行）
**特点**:
- 🤖 AI智能分析所有工具
- 📋 生成详细的删除计划
- ⚡ 自动执行删除操作
- 📊 提供完整的操作日志

**使用场景**: 日常重复工具清理，保持数据库整洁

#### `delete-with-real-service-key.js` ⭐
**功能**: 使用Service Role Key直接删除重复工具
**特点**:
- 🔑 使用Service Role Key（最高权限）
- ⚡ 快速直接删除
- ✅ 实时验证删除结果
- 🎯 100%成功率

**使用场景**: 快速删除已知重复工具

### 3. 🔍 权限检查脚本

#### `check-supabase-permissions.js`
**功能**: 检查Supabase数据库权限配置
**检查内容**:
- 👤 用户认证状态
- 📋 SELECT/INSERT/UPDATE/DELETE权限
- 🔑 API Key类型分析
- 🛡️ RLS策略检查

**使用场景**: 权限问题诊断，排查删除失败原因

#### `check-deletion-results.js`
**功能**: 验证删除操作的实际结果
**用途**:
- ✅ 确认删除成功
- 📊 统计删除数量
- 🔍 检查遗漏

**使用场景**: 删除操作后的结果验证

### 4. 📈 数据分析脚本

#### `audit-duplicate-tools.js`
**功能**: 审核重复工具，提供删除建议
**特点**:
- 🔍 检查完全相同的工具
- 📊 统计重复情况
- 💡 提供删除建议

**使用场景**: 重复工具的初步审核

#### `audit-existing-tools.js`
**功能**: 审核现有工具，检查完全重复
**特点**:
- 📋 名称完全相同检查
- 📊 生成删除SQL
- ⚡ 快速执行

**使用场景**: 快速检查完全重复的工具

#### `audit-similar-tools.js`
**功能**: 分析相似但不同的工具
**特点**:
- 🔍 检查名称相似性
- 🌐 分析域名关联
- 📝 提供人工审核建议

**使用场景**: 人工审核辅助，避免误删

#### `audit-tools-table.js`
**功能**: 审核tools表中的工具
**特点**:
- 🎯 专注于tools表
- 🤖 AI智能分析
- 🗑️ 自动执行删除

**使用场景**: tools表的重复工具清理

### 5. 🔧 维护工具脚本

#### `create-tables.js`
**功能**: 创建数据库表结构
**用途**:
- 🏗️ 初始化数据库
- 📋 创建必要表结构
- 🔧 设置索引和约束

**使用方法**:
```bash
node scripts/create-tables.js
```

#### `create-admin.sh`
**功能**: 创建管理员用户
**用途**:
- 👤 创建管理员账户
- 🔐 设置权限
- 📧 配置认证

**使用方法**:
```bash
chmod +x create-admin.sh
./create-admin.sh
```

## 🚀 使用指南

### 🎯 日常维护流程

#### 1. 快速清理重复工具
```bash
# 使用Service Role Key删除
node scripts/delete-with-real-service-key.js
```

#### 2. 全面分析清理
```bash
# AI分析 + 自动删除
node scripts/complete-duplicate-cleanup.js
```

#### 3. 权限问题排查
```bash
# 检查权限配置
node scripts/check-supabase-permissions.js
```

#### 4. 验证删除结果
```bash
# 检查删除结果
node scripts/check-deletion-results.js
```

### 📋 脚本执行顺序

#### 新项目首次清理
1. `scripts/check-supabase-permissions.js` - 检查权限
2. `scripts/audit-duplicate-tools.js` - 初步审核
3. `scripts/delete-with-real-service-key.js` - 执行删除
4. `scripts/check-deletion-results.js` - 验证结果

#### 定期维护
1. `scripts/audit-duplicate-tools.js` - 检查新增重复
2. `scripts/delete-with-real-service-key.js` - 清理重复
3. `scripts/check-deletion-results.js` - 验证清理

### ⚠️ 注意事项

#### 🔐 权限要求
- 📝 **普通操作**: 使用publishable key
- 🗑️ **删除操作**: 必须使用service role key
- 🛡️ **RLS策略**: 可能影响删除权限

#### 💾 数据安全
- 🔒 **备份建议**: 删除前备份数据
- 🧪 **测试环境**: 先在测试环境验证
- 📊 **操作日志**: 保存操作记录

#### 🔄 环境配置
- 📄 **.env文件**: 配置API密钥
- 🔑 **密钥管理**: 定期更新密钥
- 🌐 **网络连接**: 确保API访问正常

## 📞 技术支持

### 🐛 常见问题

#### Q: 删除操作失败怎么办？
A: 
1. 运行 `scripts/check-supabase-permissions.js` 检查权限
2. 确认使用service role key
3. 检查RLS策略设置

#### Q: AI分析结果不准确？
A:
1. 检查AI提示词是否合适
2. 调整AI模型参数
3. 人工审核关键结果

#### Q: 脚本运行出错？
A:
1. 检查环境变量配置
2. 确认网络连接
3. 查看错误日志
