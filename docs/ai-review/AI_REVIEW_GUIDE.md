# AI审核系统使用说明

## 功能概述

AI创客工具导航网站已集成DeepSeek AI审核系统，帮助管理员更高效地审核AI工具提交。

## 核心功能

### 1. AI自动审核
- **成熟度评估**: 评估AI工具的功能完整性、用户基数、稳定性等
- **趣味性评估**: 评估工具的创新性、实用性、独特性等
- **重复检测**: 从名称、功能、URL等多维度检测与现有工具的重复性
- **内容优化**: 自动优化工具名称、简介、描述，提供标签建议

### 2. 审核结果展示
- **评分系统**: 0-10分的成熟度和趣味性评分
- **置信度**: AI建议的可信度评分
- **详细推理**: 完整的AI分析过程和理由
- **可视化界面**: 直观的进度条和徽章展示

### 3. 批量操作
- **批量AI审核**: 一次对多个工具进行AI审核
- **应用优化建议**: 一键应用AI生成的内容优化
- **复制功能**: 快速复制AI生成的内容

## 使用方法

### 单个工具AI审核
1. 在待审核列表中找到目标工具
2. 点击"AI审核"按钮
3. 等待AI分析完成（通常需要10-30秒）
4. 查看审核结果弹窗，了解详细分析
5. 根据AI建议进行操作

### 批量AI审核
1. 勾选需要审核的工具（可全选）
2. 点击"批量AI审核"按钮
3. 等待所有工具审核完成
4. 逐个查看审核结果

### 应用AI优化
1. 在AI审核结果弹窗中查看优化建议
2. 点击"应用优化建议"按钮
3. 系统会自动更新工具的名称和简介
4. AI推理过程会保存到备注中

## 审核标准

### 成熟度评分标准
- **9-10分**: 功能完整，用户基数大，稳定可靠
- **7-8分**: 功能较完整，有一定用户，基本稳定
- **5-6分**: 功能基本可用，用户较少，可能有bug
- **0-4分**: 功能不完整，极不稳定或概念阶段

### 趣味性评分标准
- **9-10分**: 高度创新，解决重要问题，独特性强
- **7-8分**: 有一定创新，实用性强，有特色
- **5-6分**: 功能常规，实用性一般，同质化较多
- **0-4分**: 缺乏创新，实用性低，大量重复

### 重复检测标准
- **相似度>80%**: 高度重复，建议拒绝
- **相似度60-80%**: 部分重复，需要人工评估
- **相似度<60%**: 基本不重复

## 配置说明

### 环境变量配置
```env
VITE_DEEPSEEK_API_KEY=your_deepseek_api_key
VITE_DEEPSEEK_BASE_URL=https://api.deepseek.com
```

### API限制
- 为避免API限制，批量审核时每个工具间隔1秒
- 建议单次批量审核不超过10个工具
- API调用失败时会自动降级为人工审核

## 注意事项

1. **AI建议仅供参考**: 最终审核决定权在管理员
2. **API成本**: DeepSeek API按使用量计费，请合理使用
3. **数据安全**: 所有审核数据仅用于内部审核，不会外泄
4. **网络要求**: 需要稳定的网络连接调用AI服务

## 故障排除

### AI审核失败
1. 检查网络连接
2. 验证API密钥配置
3. 查看浏览器控制台错误信息
4. 尝试刷新页面重新审核

### 批量审核中断
1. 检查是否有单个工具审核失败
2. 重新选择未完成的工具进行审核
3. 考虑减少单次批量审核数量

### 优化建议未生效
1. 检查是否有数据库写入权限
2. 确认工具状态仍为待审核
3. 尝试手动刷新页面查看最新数据
