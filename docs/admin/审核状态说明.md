# 审核状态说明

## 状态标识说明

### 人工审批状态
- ✅ **已通过**: 管理员人工审批通过
- ❌ **已拒绝**: 管理员人工审批拒绝  
- ⏳ **待审批**: 等待管理员人工审批

### AI审核状态（仅在待审批时显示）
- 🤖 **AI已审核**: AI已完成审核，显示审核建议
- 🔄 **待AI审核**: 还未进行AI审核

### 操作列状态
- **AI审核中**: 显示加载动画和"AI审核中"文字
- **👍 通过/👎 拒绝/🤔 人工**: AI审核结果，括号中显示置信度
- **AI审核按钮**: 点击开始AI审核

## 工作流程

1. 工具提交后状态为"⏳ 待审批" + "🔄 待AI审核"
2. 点击"AI审核"按钮开始AI审核
3. AI审核完成后显示"🤖 AI已审核" + 审核结果
4. 管理员根据AI建议进行人工审批
5. 审批通过后状态变为"✅ 已通过"

## 表格列说明

| 列名 | 内容 |
|------|------|
| 工具信息 | Logo、名称、简介 |
| 分类 | 工具分类标签 |
| 状态 | 人工审批状态 + AI审核状态 |
| 提交时间 | 提交日期 |
| 操作 | 详情查看、AI审核、审核结果 |

## 详情弹窗

点击"详情"按钮可查看：
- 完整的工具基本信息
- AI审核结果（如果已审核）
- 优化建议和推理过程
- 应用优化建议等操作
